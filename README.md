# 🗨️ Chatterbox

A full-stack real-time chat application built using the **MERN** stack with **Socket.io** for live messaging and **Cloudinary** for image uploads. Designed for scalability, responsiveness, and smooth user experience.

---

## 🚀 Features

- 💬 Real-time one-on-one messaging (Socket.io) — tested with 100+ concurrent users
- 🔒 JWT-based authentication and authorization for secure session management
- 📸 Profile picture uploads via Cloudinary with instant UI updates
- 📦 RESTful APIs for users, chats, and messages using Express.js
- 🎨 Responsive UI using TailwindCSS and DaisyUI (25% fewer layout issues across devices)
- ⚙️ Centralized error handling and session logic for improved backend reliability

---

## 🛠️ Tech Stack

| Layer         | Technology                    |
|---------------|-------------------------------|
| **Frontend**  | React.js, TailwindCSS, DaisyUI |
| **Backend**   | Node.js, Express.js            |
| **Database**  | MongoDB                        |
| **Real-time** | Socket.io                      |
| **Uploads**   | Cloudinary                     |
| **Auth**      | JWT (JSON Web Tokens)          |
